Reaching the Mac

  • Remote Login is on (System Settings -> General -> Sharing); user shrek, the address from the owner. Key: ~/.ssh/mac_rdna3 on the Pi.
  • Many steps need root. Ask the owner once for passwordless sudo for this user (sudo visudo -f /etc/sudoers.d/rdna3, line shrek ALL=(ALL) NOPASSWD: ALL); never type the owner's password yourself.
  • The USB stick's EFI partition (OpenCore) mounts only with sudo: sudo diskutil mount disk2s1 (check diskutil list: the 61.5 GB EFI partition labelled OPENCORE) -> /Volumes/OPENCORE.

What is where on the Mac

  • OpenCore (from the stick, not yet on the internal disk): /Volumes/OPENCORE/EFI/OC/config.plist is the active config. Copies: config-driver.plist (driver, core kext injected by OpenCore, no rdna3agdc), config-metal.plist (driver + rdna3agdc=3: WindowServer on the Metal plugin), config-installer.plist (no driver), config-before-metal.plist (what metal.sh saved). Switching = copy one over config.plist, then reboot the Mac.
  • The core kext is OpenCore's: /Volumes/OPENCORE/EFI/OC/Kexts/RDNA3Accel.kext. The rest is in macOS: /Library/Extensions/RDNA3{Framebuffer,Accelerator,AGDC}.kext (and an unused RDNA3Accel copy), the Metal plugin /Library/GPUBundles/RDNA3MTLDriver.bundle, RADV and the translator in /Library/GPUBundles/rdna3mtl/, scripts and firmware in /Library/Application Support/RDNA3/.
  • Stick helper scripts (tools/baremetal/stick/, copied by make_usb.sh): /Volumes/OPENCORE/rdna3/install.sh (driver from the release tarball: the .pkg refused Tahoe before 145ca65), metal.sh (plugin + RADV + rdna3agdc=3 in config.plist), report.sh (report into /Volumes/OPENCORE/rdna3/report-<date>/: 3 h of logs, boot log, dmesg, ioreg, kexts, displays, rdna3 sysctls, crash and shutdown-stall reports). report.sh does NOT run autoreport --standalone (its display-sleep step crashed WindowServer without the plugin, fixed in f0789cb but keep it off until the plugin path is proven here).

Installing a CI build without Linux

Artifacts of the Forgejo build.yml run (token FORGEJO_TOKEN in the Pi's .env, API https://forgejo.voten.me/api/v1/repos/Voten641/RDNA3-Hackintosh, actions/artifacts?name=<name> then actions/artifacts/<id>/zip): RDNA3-pkg (the .pkg and the release tarball), RDNA3Accel-kext (all kexts incl. the core), RDNA3MTL (plugin + translator, full runs only), radv-macos-logs (install/lib/libvulkan_radeon.dylib, full or radv runs). Use ONE run's artifacts together: the kexts, the core on the stick, the plugin and RADV must come from the same commit (a mix ran on 2026-10-31).

  1. scp the tarball to the Mac, sudo sh install.sh <tarball> (or put it next to /Volumes/OPENCORE/rdna3/install.sh).
  2. Replace /Volumes/OPENCORE/EFI/OC/Kexts/RDNA3Accel.kext with the artifact's (keep the old one under EFI/OC/Kexts-old/).
  3. Plugin + RADV: put RDNA3MTLDriver.bundle, librdna3mtl_translate.dylib, libvulkan_radeon.dylib, rdna3mtl-allow.txt (repo metal/) into /Volumes/OPENCORE/rdna3/metal/, sudo sh /Volumes/OPENCORE/rdna3/metal.sh. A plugin-only update needs no reboot: log out and in, or sudo killall -HUP WindowServer (the owner logs in again).
  4. New kexts in /Library/Extensions need System Settings -> Privacy & Security -> Allow on the screen (the owner), then a reboot.

Live switches (no reboot), read back with sysctl -a | grep rdna3: debug.rdna3accel_swap_gen, debug.rdna3accel_swap_gen_cpu, debug.rdna3accel_swap_stale, debug.rdna3accel_swap_mode, debug.rdna3accel_flipbuf_present, debug.rdna3accelfb (see docs/INSTALL-OPENCORE.html section 7 and DRIVER-PLAN N65).
