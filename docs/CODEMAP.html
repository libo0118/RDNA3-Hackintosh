2.5 Framebuffer and AGDC

fb/rdna3-fb.cpp: RDNA3Framebuffer (IOFramebuffer plumbing, connection table, aperture, VBL from the core's interrupt, power states) and RDNA3_FB_CLASS = AMDRDNA3Framebuffer; talks to the core only through rdna3Display* calls (accel/rdna3k_abi.h); decisions in common/rdna3_fb_policy.h, common/rdna3_vbl_irq.h. Counters are IORegistry properties (RDNA3,FBStats). agdc/rdna3-agdc.cpp: RDNA3AGDC + RD3DeviceControl; rdna3_agdc_k5.h (0x921 link config, 0x711 plane scaler), rdna3_agdc_n48.h (Navi48-MacOS answers), AppleGraphicsDeviceControl_re.h; sysctls debug.rdna3agdc*. Build-id hashes: FB_SRC_HASH / AGDC_SRC_HASH / ACCEL_SRC_HASH in the three Makefiles must list the same files as tools/triage_reports.py (*_HASH_FILES; tests test_accel_hash_parity.py, test_fb_agdc_hash_parity.py). A new header included by a kext goes into both.

2.6 libdrm_xnu and userspace

userspace/libdrm_xnu/: drm_xnu.c/.h (a DRM fd = pipe read end; drm_xnu_open/ioctl/mmap), xf86drm_xnu.c, transports backend_iokit.c (to RDNA3UserClient) and backend_loopback.c (runs uapi/rdna3_drm.c in-process: host tests, tools/radv_host.sh), override/libdrm_macros.h. Real libdrm sources are in third_party/libdrm. Programs: rdna3_drminfo (UAPI acceptance, --dma-test, --gfx-test, --scanout[-hires], --scanout-strip FILE SECONDS (N59), --vcn-test), rdna3_modetest, rdna3_pmctl, rdna3_vktest (RADV smoke test), mtlprobe (Metal compute/render). 4. Tests and CI
