Installed. Before you restart:

  1. OpenCore (docs/INSTALL-OPENCORE.md in the repository): SIP off (csr-active-config EF0F0000), SecureBootModel Disabled, boot-arg amfi=0x80, and no WhateverGreen / device-id spoof for the RX 7800 XT. Recommended: inject the core kext with OpenCore: sudo diskutil mount disk0s1 (your EFI partition), then sudo "/Library/Application Support/RDNA3/oc_install.sh" --efi /Volumes/EFI.
  2. A way back: keep a second OpenCore entry or EFI copy without the RDNA3 kexts, or boot with -rdna3off.
  3. Restart. If macOS reports blocked system software: System Settings → Privacy & Security → Allow, then restart again.

No rdna3 boot-args are needed: the driver runs its default profile. Report for the developers: sudo "/Library/Application Support/RDNA3/autoreport.sh" --standalone (files in /Users/Shared/rdna3-reports). Uninstall: mount the EFI partition, then sudo "/Library/Application Support/RDNA3/uninstall.sh": it also removes the OpenCore copy, entries and rdna3 boot-args (--keep-opencore skips that).
